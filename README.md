\# Food Delivery Database



\## Описание проекта



Мой проект посвящён созданию базы данных для сервиса доставки еды. Я выбрал эту тему, потому что доставка еды является популярной услугой, а её работу можно представить с помощью связанных таблиц. База данных предназначена для хранения информации о ресторанах, блюдах, клиентах, заказах, оплатах и курьерах. Её могут использовать администраторы сервиса, сотрудники ресторанов и операторы доставки. В проекте создано 11 таблиц, связанных между собой первичными и внешними ключами. Таблицы dish\_category и order\_item позволяют реализовать связи многие-ко-многим. В дальнейшем система сможет обрабатывать большое количество заказов и использоваться для анализа продаж и работы доставки.

### Как применить к базе, созданной в неделю 1

1. Сделайте резервную копию базы (свой `food_delivery_full.sql` уже сохранён).
2. Откройте CMD в папке проекта `sakenuly-db`.
3. Выполните:

   ```cmd
   "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U food_app -d food_delivery -v ON_ERROR_STOP=1 -f "migrations\02_schema.sql"
   ```

4. Проверьте в `psql`: `\d food_delivery.dish_category` и `\d food_delivery.review`.

**Важно:** не запускать заново `01_init.sql` или `02_seed.sql` на уже заполненной базе. Если собираете базу по старым файлам с нуля, порядок: `01_init.sql`, затем `02_seed.sql`, затем `02_schema.sql`. Новый файл также может создать пустую структуру сразу, но старый файл наполнения `02_seed.sql` рассчитан на схему первой недели и должен выполняться **до** нормализующей миграции.
