\# Food Delivery Database



\## Описание проекта



Мой проект посвящён созданию базы данных для сервиса доставки еды. Я выбрал эту тему, потому что доставка еды является популярной услугой, а её работу можно представить с помощью связанных таблиц. База данных предназначена для хранения информации о ресторанах, блюдах, клиентах, заказах, оплатах и курьерах. Её могут использовать администраторы сервиса, сотрудники ресторанов и операторы доставки. В проекте создано 11 таблиц, связанных между собой первичными и внешними ключами. Таблицы dish\_category и order\_item позволяют реализовать связи многие-ко-многим. В дальнейшем система сможет обрабатывать большое количество заказов и использоваться для анализа продаж и работы доставки.



\## Используемые технологии



\- PostgreSQL 18

\- SQL

\- psql



\## Основные таблицы



\- restaurant — рестораны

\- category — категории блюд

\- dish — блюда

\- customer — клиенты

\- courier — курьеры

\- orders — заказы

\- order\_item — состав заказов

\- payment — оплата

\- delivery — доставка

\- review — отзывы

\- dish\_category — связь блюд и категорий
